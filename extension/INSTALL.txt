xdeporter v0.1.0 beta

1. Extract this ZIP into a permanent folder.
2. Open brave://extensions in desktop Brave.
3. Turn on Developer mode, then choose Load unpacked.
4. Select this folder (the one containing manifest.json).
5. Pin xdeporter, refresh X, and sign in normally.

Use the extension popup to choose Hide selected or Show only and select countries
or regions. Unknown locations remain visible unless you enable Hide unknown.
The master toggle restores hidden posts immediately.

This beta uses X's public Account based in estimate, not nationality. X's private
lookup endpoint has not yet been tested with a live signed-in account. If lookups
fail, check the popup status and open an account's About this account page once.
